# VS Launcher 0.10.0

VS Launcher is a text-first home screen for Android 8.0 and later. This release adds unit conversions and a configurable swipe-down gesture, and improves how Search and page transitions respond to input.

## What’s new

- **Convert units in Search.** Try `10km to mi`, `72f to c`, or `500g in oz`. Tap the result to copy it. Search for `flashlight` to toggle it on supported devices.
- **Choose what swipe down does.** In launcher Settings, set **Swipe down** to open Search or Notifications. It starts off.
- **See what Search matched.** Matches are highlighted, recent launches break ranking ties, and a progress line appears before Search automatically opens a single app result.
- **Navigate more smoothly.** App search moves with the on-screen keyboard. Page transitions follow swipe velocity, and Back supports predictive gestures where Android provides them.
- **Manage apps and configuration.** Android uninstall confirmation works again for eligible personal-profile apps. Configuration import/export runs off the UI thread.

[Compare all source changes](https://github.com/Ni-zav/vs-launcher/compare/v0.9.1...v0.10.0)

## Install or upgrade

Download **VS-Launcher-0.10.0-debug.apk** from the release assets, open it on your phone, then select **VS Launcher** under **Android Settings → Apps → Default apps → Home app**.

The published 0.9.1 APK used a different signing key. To upgrade from it, open launcher **Settings → Export config** and save the JSON file before uninstalling 0.9.1. Install 0.10.0, then choose **Settings → Import config** and select that file.

The **VS-Launcher-0.10.0-walkthrough.mp4** asset shows Home setup, search, alphabetical browsing, favorite management, and quick launch. [Screenshots and quick start](https://github.com/Ni-zav/vs-launcher/tree/v0.10.0#readme)
