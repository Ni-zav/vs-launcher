# VS Launcher 0.9.1

**First public release · 20 September 2026**

VS Launcher is a native, text-first Android home screen for people who want a quiet launcher that stays out of the way. It uses one Canvas surface, Android system APIs, direct gestures, no account, no cloud service, and no decorative UI framework.

## Highlights

### Calm, text-first Home

- Absolute-black background with a fixed neutral luminance hierarchy.
- One to eight persistent Home rows, aliases, quick-launch, rename/move/clear, and direct `+ ADD APP`.
- Independent Home alignment, vertical position, density, and Home text size.
- Optional time, date, weather, and battery status with direct tap actions.

### Search that does not steal intent

- Swipe left from Home to enter focused search; Apps browse remains one gesture away.
- Deterministic prefix, alias, initials, substring, and bounded-fuzzy ranking.
- Accent/punctuation normalization (`Pokémon` → `pokemon`, `my-app` → `my app`).
- Intent-aware singleton auto-launch with stale-generation cancellation.
- Latin IME composing text remains usable; CJK composition and unfinished utility syntax suppress accidental launch.
- Numeric-only queries wait briefly for long-press operators such as `+`.

### Useful commands in the same surface

- System settings rows for Wi-Fi, Internet, volume, Bluetooth, battery, display, sound, location, notifications, NFC, storage, keyboard, alarms, and calendar.
- Permissionless DIAL and URL actions.
- Local calculator expressions such as `23*17`.
- Timer/alarm parsing such as `timer 10m`, `timer 1h 30m`, and `alarm 07:30`.
- `help`, `guide`, and Settings → HELP open the same compact guide.
- Search-web fallback is an intent row only; VS performs no web request itself.

### Browse, profiles, and accessibility

- `#–Z` rail with available-bucket snapping and transient scrub emphasis.
- Work and Private Space containers follow Android's exposed launcher/profile state.
- Locked/paused profile apps stay out of ordinary search and persistent Home state.
- Lazy virtual accessibility nodes cover Home, Apps/search, profiles, Settings, scrolling, and Undo.

### Reversible actions

- Long-press app shortcuts, pinning, hide, Home changes, and shortcut removal.
- One transient Undo affordance reverses the most recent reversible action.
- JSON export/import uses the document picker and keeps the format versioned.

## Compatibility and privacy

- Android 8.0 / API 26 or newer.
- No `QUERY_ALL_PACKAGES`, account, analytics, contact indexing, call permission, search history, or background scheduler.
- Weather uses coarse location only; coordinates are rounded before the request and are not persisted.
- Existing 0.7–0.9 preferences and JSON configurations remain compatible.

## Install

Download the APK asset attached to the GitHub release, then open it on an Android 8.0+ device. For ADB:

```sh
adb install -r VS-Launcher-0.9.1-debug.apk
```

The debug signing key is development-only. If Android reports a signing-key mismatch, uninstall the older debug build first; uninstalling removes launcher preferences.

## Scope

This is a complete, usable first public release. It does not claim universal FPS numbers, a stable production signing identity, or security isolation for hidden apps. Device-specific performance and the Infinix/XOS manual profile path are documented separately in the repository audit and device-test notes.
